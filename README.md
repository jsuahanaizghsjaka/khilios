# khilios

VPN-сервис. Панель — Remnawave, ноды — VLESS + Reality, вход в воронку — MTProto-прокси,
продажи — Telegram-бот и сайт.

Цель первого цикла: **15–30 платящих пользователей** и проверенная воронка
«прокси → канал → триал → оплата». Не выручка. Замкнутый цикл, который потом
можно масштабировать.

Дата запуска — **20 августа 2026**, план по дням в [docs/days.md](docs/days.md).
Исходный план шёл до 15 сентября, сжат за счёт готового сайта и параллельной
юридической части. Стратегия при этом не менялась — она в [docs/plan.md](docs/plan.md).

## Главный принцип

Ноды — скот, а не питомцы. Подсети блокируют целиком, на уровне ASN, поэтому
любая нода должна разворачиваться с нуля за 20 минут по скрипту из этого репозитория.
Если что-то нельзя переподнять за час — это не строим.

## Порядок разворачивания

Порядок не переставляется: ноды получают `SSL_CERT` из панели, значит панель
существует первой; бот — тонкая обёртка над API панели, без неё ему не на чем работать.

```bash
# 1. Панель (плюс бот на этой же машине)
cd infra/panel && cp panel.env.example panel.env && nano panel.env && ./deploy-panel.sh

# 2. Нода — на каждой нодовой VPS, от root, на чистой Ubuntu 22.04/24.04
cd infra/node && cp node.env.example node.env && nano node.env && ./deploy-node.sh

# 3. Бот — обратно на панельной машине
cd infra/bot && cp bot.env.example bot.env && nano bot.env && ./deploy-bot.sh
```

`SSL_CERT` для `node.env` берётся в панели: **Nodes → Create**. Дальше нода
добавляется там же по адресу и порту из вывода скрипта.

Бот — свой, код в [bot/](bot/). Готовые (Bedolaga, remnawave-shopbot) не взяли:
весь раздел «Выключить» из чеклиста — это список того, что они делают по
умолчанию, включая рефералку при замороженной рефералке и автосписание при
обещании «автосписания нет». Подробности — в [bot/README.md](bot/README.md).

Подробности и порядок действий — в [docs/runbook.md](docs/runbook.md).
Настройка внутри бота — в [docs/bot-checklist.md](docs/bot-checklist.md), и это
не формальность: там перечислено то, что надо **выключить**, чтобы не потерять
деньги и не нарушить обещания, данные на сайте.

## Парк машин

Четыре VPS, куплены 8 августа 2026, 25,92 €/мес. Роли, продления и стоимость —
в таблице инвентаря в [docs/runbook.md](docs/runbook.md). Адресов и паролей в
репозитории нет и не будет.

Домены: `khilios.net` — сайт (Cloudflare), `basaltworks.ru` — панель и официальная
почта (Timeweb). Раздельно намеренно: блокировка домена витрины не должна уносить
панель, которая отдаёт ссылки на подписку. Про `khelios.net` из писем mhost и про
два принятых риска зоны `.ru` — в [docs/runbook.md](docs/runbook.md).

Рефералка не забыта и не отложена «на потом»: правовое заключение не рекомендует
запускать её без отдельной оценки механики, потому что «приведи друга» делает
клиентов распространителями рекламы. Подробности — в [docs/legal-review.md](docs/legal-review.md).

## Секреты

В git не попадает ничего с ключами: `node.env`, `panel.env`, `bot.env`, `.env`,
приватные ключи Reality, токены ботов, дампы панели. См. `.gitignore`.
IP-адреса машин туда тоже не кладём — публичный список серверов это готовая
карта инфраструктуры для того, кто её блокирует.

Если секрет всё же закоммичен — считать скомпрометированным и перевыпустить,
а не удалять коммит.
