# web

Сайт: главная, тарифы, установка, статус узлов и правовые страницы.
Next.js (App Router), деплой на Vercel.

Сайт нужен не ради красоты. Причин ровно две, и обе не про продажи:

1. **Telegram лежит.** Когда он недоступен, сайт — единственный способ до вас дотянуться.
2. **Страница статуса.** Это и есть отстройка от рынка, и стоит она один вечер.

## Запуск

```bash
npm install
npm run dev
```

Без переменных окружения страница статуса в разработке показывает пример из
`data/status.sample.json`. В продакшене примера не будет — только честное
«данных нет».

## Переменные окружения

| Переменная | Зачем | Обязательна |
|---|---|---|
| `STATUS_URL` | Откуда брать `status.json`, который генерирует панель | для страницы статуса |
| `NEXT_PUBLIC_BOT_URL` | Ссылка на бота, на неё ведут все кнопки | до открытия можно пустой |
| `NEXT_PUBLIC_CHANNEL_URL` | Ссылка на канал | нет |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Публичный ключ Clerk для входа и регистрации | для кабинета |
| `CLERK_SECRET_KEY` | Серверный ключ Clerk | для кабинета |

Пока `NEXT_PUBLIC_BOT_URL` пуст, кнопки показывают «Скоро открытие» вместо
битой ссылки.

## Личный кабинет

Вход, регистрация, восстановление доступа и управление сессиями работают
через Clerk. Маршруты: `/sign-in`, `/sign-up`, `/account` и
`/account/profile`. Если ключи Clerk не заданы, лендинг продолжает работать,
а кабинет показывает безопасную заглушку вместо ошибки сборки.

Для продакшена подключите Clerk в Vercel Marketplace либо добавьте две
переменные окружения из таблицы вручную. Пароли и сессии сайт самостоятельно
не хранит.

## Откуда берётся статус

Панель проверяет ноды и складывает результат в `status.json`
(`infra/panel/status-json.sh`, cron раз в 5 минут). Сайт читает его по
`STATUS_URL` — вида `https://<SUB_HOST>/status/status.json`.

Обновление на странице живое: первый снимок отдаёт сервер (страница
читается и без JavaScript), дальше браузер сам опрашивает `/api/status`
раз в 30 секунд и обновляет таблицу. Свёрнутая вкладка не опрашивается,
при возврате обновление происходит сразу.

**Если на странице «Данные о состоянии сейчас недоступны» — почти всегда
дело в `STATUS_URL`.** Проверять по порядку:

1. переменная задана в Vercel для окружения Production (не только Preview);
2. `curl https://<SUB_HOST>/status/status.json` с любой машины отдаёт JSON,
   а не 404 — за это отвечает блок `handle /status/*` в Caddy на панели;
3. на панели отработал cron `status-json.sh` и в `/etc/khilios/nodes.conf`
   есть хотя бы одна нода.

Без первого пункта код на сайте исправен, а данных нет: в продакшене
`getStatus()` возвращает `null`, потому что выдуманный статус на странице
статуса хуже её отсутствия.

Проверять ноды прямо из Next.js нельзя, хотя это и выглядит проще. Сайт живёт
на Vercel, то есть за границей, и его проверка отвечает на вопрос «доступна ли
нода из европейского дата-центра». Пользователя волнует «доступна ли она с МТС
в Казани» — а это другой ответ: блокировки живут у операторов, и снаружи их не
видно. Автопроверка ловит упавшие ноды, блокировки выставляются вручную через
файл override на панели.

Если панель не отвечает или данные старше 15 минут, страница говорит об этом
прямым текстом. Показывать вчерашнюю проверку как сегодняшнюю нельзя: страница
статуса, которая врёт уверенным голосом, хуже отсутствующей.

## Что здесь ещё не сделано

- **Правовые страницы — черновики.** На них стоит красная плашка, снимать её
  до проверки юристом нельзя. В тексте есть заглушки в квадратных скобках.
- **Страница установки — каркас.** По плану заполняется 1 сентября гифками.
  Скриншоты текстом не заменяются: инструкция с картинками режет поддержку вдвое.
- Ссылки на бота и канал появятся после недель 3 и 4.

## Правила для текстов

- Не обещать того, чего не выполнить. Никаких «работает всегда» и «обход
  белых списков» — Reality маскируется под реальный сайт, и при белом списке
  этот сайт сам недоступен.
- Не писать «мы не храним логи», если это не проверено. Это самое частое
  враньё на рынке и одновременно обязательство, которое придётся выполнять.
- Продаём не VPN, а «не надо разбираться». Настоящий конкурент — бесплатная
  Amnezia, которую поставит любой, кто готов читать инструкцию.

## Индексация

В `layout.tsx` стоит `robots: noindex`. Это не ошибка: реклама и продвижение
таких сервисов в РФ запрещены с марта 2024, поэтому SEO в плане нет намеренно.
Люди приходят из бота и канала.
